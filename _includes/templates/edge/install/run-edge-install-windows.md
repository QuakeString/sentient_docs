
Launch windows shell (Command Prompt) as Administrator. Change directory to your SENTIENT GATEWAY installation directory.

Execute **install.bat** script to install SENTIENT GATEWAY as a Windows service.
This means it will be automatically started on system startup. 
Similar, **uninstall.bat** will remove SENTIENT GATEWAY from Windows services.
The output should be similar to this one:

  ```text
C:\Program Files (x86)\tb-edge\install.bat
Detecting Java version installed.
CurrentVersion 110
Java 11 found!
Installing Sentient Edge...
...
SENTIENT GATEWAY installed successfully!
```
