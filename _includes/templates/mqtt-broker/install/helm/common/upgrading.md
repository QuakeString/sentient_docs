Helm support was introduced with the ST-RMQTT 2.1.0 release. Starting with the ST-RMQTT 2.2.0 release, 
the Helm chart was updated to version [1.1.0](https://artifacthub.io/packages/helm/st-rmqtt-helm-chart/st-rmqtt-cluster/1.0.0?modal=changelog&version=1.1.0), which introduced upgrade options. 
For detailed instructions on how to upgrade your ST-RMQTT Helm deployment, please refer to the
[Upgrading](https://artifacthub.io/packages/helm/st-rmqtt-helm-chart/st-rmqtt-cluster#upgrading) 
section of the ST-RMQTT Helm Chart documentation on Artifact Hub.
