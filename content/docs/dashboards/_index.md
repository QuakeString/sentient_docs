SENTIENT's dashboards work like the classic editor described in [Dashboards](/docs/user-guide/dashboards/), with these additions for plant screens.

| Feature | What it gives you | Since |
|---|---|---|
| [Industrial equipment widgets](/docs/dashboards/industrial-widgets/) | 46 animated pumps, fans, motors, valves, conveyors, hoppers and burners that move with live data | 4.3.0.57 |
| [Split views](/docs/user-guide/dashboards/#show-several-dashboards-on-one-screen) | Several dashboards side by side on one screen | 4.3.0.57 |
| [Kept-open dashboards](/docs/user-guide/dashboards/#keep-dashboards-open-in-memory) | Switching between control-room screens without reloading them | 4.3.0.57 |
| Condition monitoring widgets | Spectrum, waveform, waterfall, health score and work orders for [asset health](/docs/asset-health/) | 4.3.0.57 |
| [Drafts and crash recovery](/docs/dashboards/crash-recovery/) | Unsaved edits survive a browser crash; undo uses far less memory | The release after 4.3.0.57 |
