SENTIENT API consists of two main parts: device API and server-side API.

Device API is grouped by supported communication protocols:

* [**MQTT API**](/docs/edge/reference/mqtt-api)
* [**CoAP API**](/docs/edge/reference/coap-api)
* [**HTTP API**](/docs/edge/reference/http-api)
* [**LWM2M API**](/docs/edge/reference/lwm2m-api)
* [**SNMP API**](/docs/edge/reference/snmp-api)

[**Gateway MQTT API**](/docs/edge/reference/gateway-mqtt-api) allows you to connect **existing** devices to the platform using **[SENTIENT IoT Gateway](/docs/iot-gateway/what-is-iot-gateway/)**
or implement your own gateway.
