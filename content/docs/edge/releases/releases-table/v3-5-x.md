## v3.5.0 (May 10, 2023)

**Major** release with everything from [TB CE v3.5](/docs/releases/releases-table/v3-5-x/#sentient-ce-v350-may-9-2023) with the following improvements and bug fixes:

* [#7862](https://github.com/sentient/sentient/pull/7862) Push latest timeseries key-value pair to edge on assignment entity to edge;
* [#7878](https://github.com/sentient/sentient/pull/7878) Add edge install instructions for docker;
* [#7914](https://github.com/sentient/sentient/pull/7914) Added default edge rule chain to asset/device profiles;
* [#8301](https://github.com/sentient/sentient/pull/8301) Edge computing solution templates;
* [#8340](https://github.com/sentient/sentient/pull/8340) Handle gRPC messages exceeding default max message size;
* [#8344](https://github.com/sentient/sentient/pull/8344) Push edge connect/disconnect events to rule chain;
* [#8346](https://github.com/sentient/sentient/pull/8346) Improved Keep Alive Functionality between Edge and Cloud to Prevent Data Loss;
