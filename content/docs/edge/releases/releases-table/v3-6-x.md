## v3.6.4 (Apr 11, 2024)

**Minor** release with everything from [TB CE v3.6.4](/docs/releases/releases-table/v3-6-x/#sentient-ce-v364-apr-11-2024).
## v3.6.3 (Mar 18, 2024)

**Minor** release with everything from [TB CE v3.6.3](/docs/releases/releases-table/v3-6-x/#sentient-ce-v363-mar-18-2024):

* [#9968](https://github.com/sentient/sentient/pull/9968) Alarm comment support by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#10021](https://github.com/sentient/sentient/pull/10021) Notification rules for connection status and errors. Rate limits for Edge events by [@AndriiLandiak](https://github.com/AndriiLandiak);

## v3.6.2 (Dec 28, 2023)

**Minor** release with everything from [TB CE v3.6.2](/docs/releases/releases-table/v3-6-x/#sentient-ce-v362-dec-28-2023):

* [#9688](https://github.com/sentient/sentient/pull/9688) Edge upgrade instructions in TB Server by [@AndriiLandiak](https://github.com/AndriiLandiak) and [@deaflynx](https://github.com/deaflynx);
* [#9617](https://github.com/sentient/sentient/pull/9617) Edge - JSON converter for proto by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#9712](https://github.com/sentient/sentient/pull/9712) Edge Requests Service - fetch only first level of relation from cloud by [@volodymyr-babak](https://github.com/volodymyr-babak); 
## v3.6.1 (Nov 14, 2023)

**Minor** release with everything from [TB CE v3.6.1](/docs/releases/releases-table/v3-6-x/#sentient-ce-v361-nov-13-2023) with the following improvements and bug fixes:

* [#9226](https://github.com/sentient/sentient/pull/9226) TB Resource functionality support for Edge by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#9515](https://github.com/sentient/sentient/pull/9515) Increased default value of EDGES_SLEEP_BETWEEN_BATCHES to handle 2G/3G connections by [@volodymyr-babak](https://github.com/volodymyr-babak);
## v3.6.0 (Sep 22, 2023)

**Major** release with everything from [TB CE v3.6](/docs/releases/releases-table/v3-6-x/#sentient-ce-v360-sep-21-2023) with the following improvements and bug fixes:

* [#9087](https://github.com/sentient/sentient/pull/9087) Add possibility to create Assets, Dashboards, EntityViews, AssetProfile, DeviceProfile on edge by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#9062](https://github.com/sentient/sentient/pull/9062) Push tenant and tenant profile entities to the edge by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#9052](https://github.com/sentient/sentient/pull/9052) Introduce Event Pub/Sub Model for Detecting Changes in Entities by [@AndriiLandiak](https://github.com/AndriiLandiak);
* [#8830](https://github.com/sentient/sentient/pull/8830) Edge event table - added sequential ID column to handle properly heavy load and cluster cases by [@volodymyr-babak](https://github.com/volodymyr-babak);
* [#9245](https://github.com/sentient/sentient/pull/9245) Edge instructions for ubuntu, centos by [@deaflynx](https://github.com/deaflynx) and [@AndriiLandiak](https://github.com/AndriiLandiak);
