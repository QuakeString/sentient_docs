## v4.2.1 (Jan 21, 2026)

**Minor** release with everything from [TB CE v4.2.1](/docs/releases/releases-table/v4-2-x/#sentient-ce-v421-oct-15-2025):

**Bug fixes**

* **Consumer loop commit failures:** Fixed an issue where the cloud consumer failed when the connection to the cloud was closed for longer than the configured Kafka consumer poll timeout.

## v4.2.0 (Sep 4, 2025)

**Major** release with everything from [TB CE v4.2.0](/docs/releases/releases-table/v4-2-x/#sentient-ce-v420-aug-15-2025):

**Improvements**

* [#13651](https://github.com/sentient/sentient/pull/13651) **Downlink queue statistics:** Introduced support for reporting Downlink queue metrics as timeseries telemetry by [@jekka001](https://github.com/jekka001);
* [#184](https://github.com/sentient/sentient-gateway/pull/184) **Uplink queue statistics:** Introduced support for reporting Uplink queue metrics as timeseries telemetry by [@jekka001](https://github.com/jekka001);

**Bug fixes**

* [#194](https://github.com/sentient/sentient-gateway/pull/194) **Kafka Pending Events Issue During Sync:** Added buffering of pending events and ensured they are processed once sync is complete by [@jekka001](https://github.com/jekka001);
* [#182](https://github.com/sentient/sentient-gateway/pull/182) **Timeseries Uplink Fixes:** Ensure Timeseries Events Are Not Dropped After X Delivery Attempts by [@volodymyr-babak](https://github.com/volodymyr-babak);
* [#13599](https://github.com/sentient/sentient/pull/13599) **Rule Chain Sync Fixes:** Fixes rule chain updates from Edge to Cloud by [@jekka001](https://github.com/jekka001);
