The **IEC 61850** connector reads substation devices (IEDs: protection relays, bay controllers, power meters) over **MMS** (TCP port **102**), receives their **buffered reports**, listens to **GOOSE** messages, and operates their controls. It does not need libiec61850 or any vendor tool.

## Add an IED

1. In SENTIENT, open the gateway, then **Connectors**, and add an **IEC 61850** connector.
2. Add a device and fill in:

   | Setting | Value |
   |---|---|
   | **Device Name**, **Device profile** | The device in SENTIENT |
   | **Host**, **Port** | The IED's IP address, port `102` |
   | **Acquisition Mode** | **Polling**: the gateway reads the values every **Poll Period (ms)**. **Report (BRCB)**: the IED sends changes itself, through a buffered report control block |
   | **Connection Timeout (ms)**, **Connect Attempts**, **Wait After Failed (ms)** | Under **Advanced connection settings** |

3. Add keys (below), click **Apply**, and save the connector.

### Reports

With **Report (BRCB)**, fill in **Report Configuration (BRCB)**:

| Setting | Value |
|---|---|
| **RCB Reference** | The report control block, for example `simpleIOGenericIO/LLN0$BR$brcb01` |
| **Report ID** | Optional |
| **Integrity Period (ms)** | A full snapshot every so often. `0` turns it off |
| **Buffer Time (ms)** | How long the IED collects changes before it sends a report |
| **Trigger Options** | **Data Change**, **Quality Change**, **Data Update**, **Integrity**, **General Interrogation** |

Each report control block can serve only one client at a time. Choose a block that the station's SCADA does not already use.

## Keys

Each key has a **Tag** (the key's name in SENTIENT), a **Reference** and a **Functional Constraint**:

- **Reference**: the object path, for example `GenericIO/GGIO1.AnIn1.mag.f` or `LD0/MMXU1.TotW.mag.f`.
- **FC**: `ST` (status), `MX` (measured values), `CO` (control), `SP` (settings) and so on.
- **Value type**: `boolean`, `int32`, `unsigned`, `float`, `double` or `string`, or **Auto** to take the type from the IED.
- **Scaling** maps **Raw Min** to **Raw Max** onto **Eng Min** to **Eng Max**.

**Browse IED** (**Discover Data Model**) reads the IED's data model and lists its data points. Tick them and click **Add to Telemetry**, **Add to Attributes**, **Add to Attribute Updates** or **Add to RPC Methods** (with **Writable data points only** for the last two). Points you already have are marked **Already configured**.

## Controls and writes

Under **RPC Methods**, each method has an **Operation**:

- **Read** gets the value, **Write** sets it (for example a setting in `SP`).
- **Control** runs the IEC 61850 control sequence on a `CO` object, for example opening a breaker (`XCBR1.Pos`). Choose the **Control model** the IED uses: **Direct Normal**, **SBO Normal**, **Direct Enhanced** or **SBO Enhanced**. SBO (select before operate) selects the object first and operates only if the selection succeeded.

## GOOSE

Under **GOOSE Configuration**, set the **Network Interface** that receives the station bus multicast (for example `eth0`), then **Add Subscription** for each GOOSE control block: **GoCB Reference** (for example `simpleIOGenericIO/LLN0$GO$gcb01`) and **App ID** in hex (for example `0001`).

GOOSE uses raw Ethernet: in Docker, run the gateway with `network_mode: host` and `cap_add: [NET_RAW]`.

## TLS

For IEDs that secure MMS with TLS (IEC 62351), fill in **TLS Security (IEC 62351)**: **CA Certificate**, and the **Client Certificate** and **Client Key** if the IED checks the gateway. These are file paths on the gateway.

## When something is wrong

| What you see | What to do |
|---|---|
| The report never arrives | The block is in use by another client, or its reference is wrong. Try another BRCB instance (`brcb02`) |
| A key reports nothing | Check the **FC**: a measured value is `MX`, a status `ST`. **Browse IED** shows the right one |
| A control is refused | The **Control model** does not match the IED, or the IED is in local mode |
| No GOOSE values | Check the **Network Interface**, the **App ID**, and that the gateway runs with raw network access |
