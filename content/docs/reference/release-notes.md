What changed in each SENTIENT release, newest first. Downloads for every release (Windows and Linux packages, the mobile app and the gateway) are on the [SENTIENT release page](https://github.com/QuakeString/sentient-release/releases); the Docker image is `quakestring/sentient:<version>`. To update, see [Upgrade and roll back](/docs/operations/upgrade/).

## 4.3.0.57 (2026-11-03)

License limits edited on the license server reach a running SENTIENT at its next heartbeat.

#### Added
- The license heartbeat takes up limits the license server re-signed after an
  admin edited a license in use, and applies them at once. The new payload must
  verify, be for the same license and hardware, and be newer than the current
  one.
- `manifest.json` lists the SHA-256 of the server program for Windows, Linux
  and the Docker image, so the license server knows the build.

## 4.3.0.56 (2026-11-02)

Faster dashboard and SCADA screen opening, alarms pushed live to every open dashboard, and SENTIENT names in the mobile app and gateway extension.

#### Added
- Housekeeper settings can be set from environment variables, including
  `HOUSEKEEPER_PURGE_ORPHAN_TELEMETRY` to reclaim orphan telemetry rows.

#### Changed
- Dashboards show their first widgets before building the rest.
- The server caches the built dashboard bundle: a 192-symbol dashboard takes
  about 8 ms on the server instead of 97 ms.
- Large SCADA dashboards open faster: the live-data connection starts while the
  dashboard loads, and text is measured without layout.
- Widgets cost less to create: hidden export and full-screen buttons are no
  longer built.
- SCADA symbol animations run on the browser's animation engine, with a shared
  clock and frame-rate cap.
- Belt conveyor animation runs on GPU layers and pauses when off screen.
- Login page: "IIoT PLATFORM" tagline in the logo blue.
- Gateway extension: labels say SENTIENT; tidier keys
  panel.

#### Fixed
- Every alarm change (raise, acknowledge, clear, delete), from any source,
  reaches open dashboards and alarm tables over the websocket at once.
- Alarm-mapped SCADA symbols load their state when the dashboard opens.
- The mobile app logs in again: the server reports a numeric version, and
  user-visible texts say SENTIENT.
- Isolator with earth switch shows both blades.
- Text Box and Text Label show their static text by default.
- Colour picker: the value row fits beside the eyedropper.
- Widget settings: the value converter knows the picked keys, and key chips are
  editable.

#### Removed
- The experimental "New renderer for SCADA symbols" dashboard setting, added
  during this release and taken out again.

## 4.3.0.55 (2026-10-28)

Gateway extension: add read keys to RPC write and attribute updates in one step.

Built from master `4a0d08b9`. Works with Sentient Gateway 4.13.3.

#### Added
- Gateway extension: tick read keys and add them to RPC write or attribute
  updates, with the same address and data type.

## 4.3.0.54 (2026-10-27)

The full release version is shown in the UI and reported by the server.

Built from master `32ea5be4`. Works with Sentient Gateway 4.13.1.

#### Fixed
- The login page, dashboard footer and `/api/system/info` show the full release
  version (for example 4.3.0.54) instead of 4.3.0.

## 4.3.0.53 (2026-10-27)

Configuration edited on a gateway's own page is taken up by the platform, a new login brand lockup, and updated translations.

Built from master `be5b1a7f`. Needed by Sentient Gateway 4.13.0.

#### Added
- Configuration edited on a gateway's own local page is taken up by the
  platform.

#### Changed
- Login: brand lockup with the IIoT PLATFORM tagline; faint mark tile in dark
  mode.
- 36 changed UI texts translated in every language.

#### Fixed
- A script calculated field shows its saved script when the page loads slowly.

#### Known issues
- This build shows its version as 4.3.0; fixed in 4.3.0.54.

## 4.3.0.52 (2026-10-26)

AI script assist in script editors, and alarm details from the alarm widget.

#### Added
- AI script assist and AI suggestions in script editors.
- Alarm widget: click a row to open the alarm's details.

## 4.3.0.51 (2026-10-26)

3-position selector switch, smoother belt conveyor, hopper and chute animation, alarm details and notification links, and many dashboard and search fixes.

#### Added
- Selector switch, 3 position (AUTO / SEMI / MAN), as its own widget.
- Belt conveyor: "Hide directional arrows when not running", "Animate belt and
  rollers", a frame-rate cap and a Feed chute switch.
- Alarms: click an alarm row to open its details; the details dialog shows the
  alarm's details as written.
- Notifications: click an alarm notification to open the alarm.
- Widgets: Get value reads several keys.
- Nightly SENTIENT builds are published on sentient-release (tag `nightly`) for
  the Platform Manager's Nightly channel.

#### Changed
- Belt conveyor, hoppers and chutes move on the GPU; fault blink uses opacity in
  every symbol.
- Vibro feeder shows the active colour while running.
- Alarm Details is a standard field, tinted by severity.

#### Fixed
- Belt conveyor error at zero size, and material shown for loads under 5 %.
- Colour picker: the eyedropper works in every browser and picks the colour
  actually shown.
- A gateway sub-device gets its gateway in the description, not the label.
- Alarm rules: a script condition reopens in Script mode.
- Breadcrumb follows the regrouped side menu.
- Dashboards: the selection box and the list-view notice draw above widgets;
  the whole hovered area of the dashboard selector opens the list; faint
  "Powered by" footer, hidden in edit mode.
- Search opens dashboards for users kept in a full-screen home dashboard; the
  clear button and text fit inside the search pill.
- Widget buttons no longer fade on hover.

## 4.3.0.50 (2026-10-24)

OPC UA device discovery by NodeId, new hopper and selector switch options, and a fix for telemetry on a non-partitioned ts_kv.

#### Added
- Hopper: top cover switch and left-hand outlet.
- Selector switch: 3-position option (AUTO / OFF / MAN).
- Runtime language button, dialogs dragged by their title bar, Shift+drag for
  widgets, and a colour eyedropper.

#### Changed
- Gateway extension: OPC UA Discover Devices maps folders by NodeId with their
  variables; full screen and compact layout on both discover dialogs.

#### Fixed
- Telemetry on a non-partitioned `ts_kv` table no longer fails: only a
  partitioned table takes monthly partitions.

## 4.3.0.49 (2026-10-24)

Asset health, the AI platform and Solution hub, SENTIENT in 57 languages, the Valves bundle, split views and a new app shell.

Built from master `5494e10b`. The first release on sentient-release (Windows x64
payload with PostgreSQL 18.6, TimescaleDB 2.29.2 and the VC++ runtime; the Linux
x86_64 payload was added later). Changes
since 4.3.0.42:

#### Added
- **Asset health**: diagnosis engine, condition monitoring widgets and the Asset
  Health Monitoring solution; findings to alarms, work orders, remaining life,
  sound captures, pump efficiency, AI health tools, phone commissioning, fault
  rules, FFT workbench, 3D waterfall, bearing catalogues and a tenant bearing
  library, and one overview page per plant.
- **AI platform**: AI assistant, Solution hub with rule chains and analytics
  pipelines, and a secrets store.
- **Translation**: SENTIENT in 57 languages, AI models and the SENTIENT
  translator as translation engines, and admin-editable app texts.
- **Valves bundle**: 33 sprite-frame 3D valve and strainer symbols.
- Split views (dashboards of dashboards), SCADA "Fit to screen", profile photos,
  global search, and a new app shell with a grouped side menu.
- Widget drawer in the top bar with smart search, pinned favourites, saved time
  windows, and a pop-out widget properties window.
- Rule chain editor: zoom, pan and a glass node library.
- Switchgear operated from a confirm dialog, with title options, state colours
  and a local/remote row.
- Language switcher widget; QR code card per tenant with a per-user switch.
- Notifications: per-rule "Don't notify the person who did it".
- Gateways: the Launch command installs the Rust gateway (sentient-gateway-rs).
- ClickHouse insert time limits and attempts can be set from the environment
  (`CLICKHOUSE_INSERT_SEND_TIMEOUT_SECS`, `CLICKHOUSE_INSERT_TIMEOUT_SECS`,
  `CLICKHOUSE_INSERT_ATTEMPTS`).
- Profile: dashboards kept in memory as a number, limited by
  `DASHBOARD_KEEP_ALIVE_MAX`; up to 10 by default.

#### Changed
- Login page and user menu redesigned.
- Pill-shaped 32 px search boxes, 8 px corners on buttons and form boxes, one
  standard hint icon.
- Device type follows the device profile's name.

#### Fixed
- ClickHouse history writes are time-limited and retried, and stuck batches are
  reported, so history no longer stops silently.
- No panic when the server stops with open websocket connections.
- A parked dashboard no longer takes app-wide toasts.
- Consolidated symbols keep their layer order and widget titles in view mode.
- SCADA text fits its symbol on any screen; fit to screen no longer zooms in and
  out with the grid's scrollbar.
- Version control: a local-only repository saves without a URL.
- Dialogs no longer flicker when a date-time picker opens.
