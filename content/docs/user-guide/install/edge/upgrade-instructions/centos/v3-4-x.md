## Backup before upgrading


<div class="st-callout info">


Make sure your system has enough free space to store the backup.


</div>


Stop the SENTIENT Edge service to prevent data writes during the upgrade:

```bash
sudo systemctl stop tb-edge
```


Create the backup:

```bash
sudo -Hiu postgres pg_dump tb_edge > tb_edge.sql.bak
```


Verify the backup was created successfully:

```bash
ls -lh tb_edge.sql.bak
```


### Restore the backup (if needed)

Stop the **SENTIENT Edge** service (if it's still running):

```bash
sudo systemctl stop tb-edge
```


To restore the **PostgreSQL database** from a backup file, run the following command: 

```bash
 sudo -u postgres psql tb_edge < tb_edge.sql.bak
 ```


Start the **SENTIENT Edge** service:

```bash
sudo systemctl start tb-edge
```


## Upgrading Edge CE to 3.4.3


<div class="st-callout warn">


Ensure your <b>SENTIENT Server is up to date</b> before updating SENTIENT Edge.

If your Server version is outdated, [upgrade it first](/docs/user-guide/install/upgrade-instructions/centos/v3-4-x/#upgrading-sentient-ce-to-343/).

The following instructions are applicable for <b>SENTIENT Edge 3.4.1</b> version.


</div>


### Download the Edge package

```bash
wget https://github.com/sentient/sentient-gateway/releases/download/v3.4.3/tb-edge-3.4.3.rpm
```


Stop the SENTIENT Edge service before upgrading to prevent file conflicts:

```bash
sudo service tb-edge stop
```


### Upgrade the package

```bash
sudo rpm -Uvh tb-edge-3.4.3.rpm
```


**Note:** The package installer may prompt you to merge configuration files. Select the **merge option** to preserve your existing settings.

Execute the upgrade script to migrate your data and configurations:

```bash
sudo /usr/share/tb-edge/bin/install/upgrade.sh --fromVersion=3.4.1
```


### Start the Edge service

```bash
sudo service tb-edge start
```
