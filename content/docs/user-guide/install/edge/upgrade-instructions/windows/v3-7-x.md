## Backup before upgrading


<div class="st-callout info">


Make sure your system has enough free space to store the backup.


</div>


Stop the Edge service:

```
net stop tb-edge
```


To back up the database, follow these steps:

1. Launch **pgAdmin** and log in as the **postgres** superuser.
2. In the left sidebar, expand your server and locate the **tb_edge** database.
3. Right-click **tb_edge** and select **Backup**.
4. In the **Backup Dialog**, specify a filename and location for your backup.
5. Click **Backup** to create the backup file.


## Upgrading Edge CE to 3.7.0


<div class="st-callout warn">


Ensure your <b>SENTIENT Server is up to date</b> before updating SENTIENT Edge.

If your Server version is outdated, [upgrade it first](/docs/user-guide/install/upgrade-instructions/windows/v3-7-x/#upgrading-sentient-ce-to-37/).

The following instructions are applicable for <b>SENTIENT Edge 3.6.4</b> version.


</div>


<div class="st-callout warn">


**Important note before upgrading to SENTIENT 3.7**

SENTIENT backend was migrated to Java 17. Install JDK 17 and ensure that system's default Java version is set to 17.

Please refer to [**Step 1 of the installation guide**](/docs/user-guide/install/windows/#step-1-install-java-17-openjdk) for detailed instructions.


</div>


### Download the Edge package

Download SENTIENT Edge package for Windows: [tb-edge-windows-3.7.zip](https://github.com/sentient/sentient-gateway/releases/download/v3.7/tb-edge-windows-3.7.zip).

Stop the Edge service:

```
net stop tb-edge
```


Make a backup of your SENTIENT Edge configuration located in **\<SENTIENT Edge install dir\>\conf** (for example, **C:\tb-edge\conf**).

Extract and update configuration:
* Extract the SENTIENT Edge package.
* Compare your old configuration files (from the backup) with the new ones.
* Merge any custom settings into the new configuration files.

### Run the upgrade script

**Note:** The upgrade script must be run with Administrator privileges.

```
C:\tb-edge>upgrade.bat --fromVersion=3.6.4
```


### Start the service

```
net start tb-edge
```
