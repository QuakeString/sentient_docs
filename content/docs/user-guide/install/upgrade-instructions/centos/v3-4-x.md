### Upgrading SENTIENT to 3.4.4


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.4.3.
In order to upgrade to 3.4.4 you need to [**upgrade to 3.4.3 first**](#upgrading-sentient-ce-to-343).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.4.4/sentient-3.4.4.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.4.4.rpm
```


#### Start the service


```bash
sudo service sentient start
```

### Upgrading SENTIENT to 3.4.2


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.4.1.
In order to upgrade to 3.4.2 you need to [**upgrade to 3.4.1 first**](#upgrading-sentient-ce-to-341).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.4.2/sentient-3.4.2.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.4.2.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh --fromVersion=3.4.1
```


#### Start the service


```bash
sudo service sentient start
```


<div class="st-callout info">


Update the JWT signing key if you use the default one "sentientDefaultSigningKey" on production environments. See [JWT security settings](/docs/user-guide/ui/security-settings/#jwt-security-settings) for details.


</div>
