### Upgrading SENTIENT to 3.5.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.5.
In order to upgrade to 3.5.1 you need to [**upgrade to 3.5 first**](#upgrading-sentient-ce-to-35).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.5.1/sentient-3.5.1.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.5.1.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh --fromVersion=3.5.0
```


#### Start the service


```bash
sudo service sentient start
```


### Upgrading SENTIENT to 3.5


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.4.4.
In order to upgrade to 3.5 you need to [**upgrade to 3.4.4 first**](/docs/user-guide/install/upgrade-instructions/centos/v3-4-x/#upgrading-sentient-ce-to-344).


</div>


<div class="st-callout warn">


**Important note before upgrading to SENTIENT 3.5**

SENTIENT UI was migrated to Angular 15. You need to re-build your custom widgets and rule nodes (which use UI) on Angular 15.

We suggest consulting [**this guide**](https://v15.material.angular.io/guide/mdc-migration).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.5/sentient-3.5.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.5.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh --fromVersion=3.4.4
```


#### Start the service


```bash
sudo service sentient start
```
