### Upgrading SENTIENT to 3.9.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.9.
In order to upgrade to 3.9.1 you need to [**upgrade to 3.9 first**](#upgrading-sentient-ce-to-39).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.9.1/sentient-3.9.1.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.9.1.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```


### Upgrading SENTIENT to 3.9


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.8.1.
In order to upgrade to 3.9 you need to [**upgrade to 3.8.1 first**](/docs/user-guide/install/upgrade-instructions/centos/v3-8-x/#upgrading-sentient-ce-to-381).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.9/sentient-3.9.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-3.9.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh --fromVersion=3.8.1
```


#### Start the service


```bash
sudo service sentient start
```
