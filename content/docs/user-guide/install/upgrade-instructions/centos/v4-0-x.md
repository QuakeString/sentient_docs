### Upgrading SENTIENT to 4.0.2


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.9.x.
In order to upgrade to 4.0.2 you need to [**upgrade to 3.9.x first**](/docs/user-guide/install/upgrade-instructions/centos/v3-9-x/#upgrading-sentient-ce-to-391).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.0.2/sentient-4.0.2.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-4.0.2.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```
