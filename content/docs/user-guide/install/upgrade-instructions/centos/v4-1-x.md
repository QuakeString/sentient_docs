### Upgrading SENTIENT to 4.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.0.x.
In order to upgrade to 4.1 you need to [**upgrade to 4.0.x first**](/docs/user-guide/install/upgrade-instructions/centos/v4-0-x/#upgrading-sentient-ce-to-402).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.1/sentient-4.1.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-4.1.rpm
```


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```
