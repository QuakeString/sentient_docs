### Upgrading SENTIENT to latest 4.3.x (4.3.1.1)


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.1+.
In order to upgrade to 4.3.1.1 you need to [**upgrade to 4.2.1.x first**](/docs/user-guide/install/upgrade-instructions/centos/v4-2-x/#upgrading-sentient-ce-to-421x).


</div>


<div class="st-callout warn">


Starting with version 4.3.1, the platform uses Angular 20 (upgraded from Angular 18). The core platform remains fully backward compatible and no upgrade scripts are required. However, **custom UI code** (widgets or custom CSS) that relies on internal component structure or CSS variable names **may break**. This can affect up to ~1% of users with heavy customizations. We recommend testing custom UI in a staging environment before upgrading.


</div>


<div class="st-callout warn">


**Compatibility check before upgrading**

If you are using Edge together with SENTIENT, verify that your target SENTIENT version is compatible with the currently installed Edge version. Upgrade it if required to ensure compatibility.

- **Edge:** [Releases table](/docs/edge/releases/releases-table/)  


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.3.1.1/sentient-4.3.1.1.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-4.3.1.1.rpm
```


<div class="st-callout warn">


If you are upgrading from 4.2.1+, you **must** run the script below. However, if you are upgrading from version 4.3.0+, **DO NOT** run the upgrade script; proceed directly to starting the service.


</div>


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```


    


### Upgrading SENTIENT to 4.3.0.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.1.x or any 4.3.0 patch.
In order to upgrade to 4.3.0.1 you need to [**upgrade to 4.2.1.x first**](/docs/user-guide/install/upgrade-instructions/centos/v4-2-x/#upgrading-sentient-ce-to-421x).


</div>


<div class="st-callout warn">


This version has known security vulnerabilities that are fixed in newer releases. We recommend upgrading to the latest patch version instead.


</div>


<div class="st-callout warn">


**Compatibility check before upgrading**

If you are using Edge together with SENTIENT, verify that your target SENTIENT version is compatible with the currently installed Edge version. Upgrade it if required to ensure compatibility.

- **Edge:** [Releases table](/docs/edge/releases/releases-table/)  


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.3.0.1/sentient-4.3.0.1.rpm
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo rpm -Uvh sentient-4.3.0.1.rpm
```


<div class="st-callout warn">


If you are upgrading from 4.2.1+, you **must** run the script below. However, if you are upgrading from version 4.3.0.x, **DO NOT** run the upgrade script; proceed directly to starting the service.


</div>


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```
