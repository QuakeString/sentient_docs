### Upgrading SENTIENT to latest 4.2.x (4.2.2.1)


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.0+.
In order to upgrade to 4.2.2.1 you need to [**upgrade to 4.2.0 first**](#upgrading-sentient-ce-to-42).


</div>


<div class="st-callout warn">


We strongly recommend that you also update your Docker Compose deployment manifests to [**the corresponding version from GitHub repository**](https://github.com/sentient/sentient/tree/v4.2.2.1/docker) with every SENTIENT upgrade. This ensures your SENTIENT service runs with the latest best-practice parameters and configurations, while also guarantees that all required services are correctly deployed to support the newest features introduced in the release.
<br>
<br>
If you are running older releases of SENTIENT - be aware that the manifests in `master` branch of the repository may contain configurations for features that are not available in your specific version. Always ensure that manifests are compatible with your target SENTIENT version while merging deployment files.


</div>

#### SENTIENT service upgrade


1. Change the parameter `TB_VERSION` in the `.env` file.

```.env
TB_VERSION=4.2.2.1
```

2. Execute the following commands:
    
```bash
./docker-stop-services.sh  
```
  


<div class="st-callout warn">


If you are upgrading from 4.2, you **must** run the script below. However, if you are upgrading from version 4.2.1+, **DO NOT** run the upgrade script; proceed directly to starting the service.


</div>


```bash
./docker-upgrade-tb.sh
```
  

```bash
./docker-start-services.sh
```
