### Upgrading SENTIENT to 3.1.1

**NOTE**: These upgrade steps are applicable for SENTIENT version 3.1. In order to upgrade to 3.1.1 you need to [**upgrade to 3.1CE first**](#upgrading-sentient-ce-to-31).

#### SENTIENT image download

Download SENTIENT Docker image:

```bash
docker pull sentient/tb-postgres:3.1.1
```


#### SENTIENT service upgrade

* Stop SENTIENT `mytb` container if it is running.

```bash
docker compose stop mytb
```
 


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose stop mytb**


</div>


* Update docker-compose.yml

```yml
< . . . >
  mytbce:
    image: "sentient/tb-postgres:3.1.1"
< . . . >
```


* Change `upgradeversion` variable:

```bash
echo '3.1.0' | sudo tee ~/.mytb-data/.upgradeversion
```


* Execute the following commands to upgrade SENTIENT to the new version:

```bash
docker run -it -v ~/.mytb-data:/data --rm sentient/tb-postgres:3.1.1 upgrade-tb.sh
```


* Start SENTIENT:

```bash
docker compose up -d
```


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose up -d**


</div>
