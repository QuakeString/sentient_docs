### Upgrading SENTIENT to 3.4.4


<div class="st-callout info">


**NOTE:**
<br>
These upgrade steps are applicable for SENTIENT version 3.4.3. In order to upgrade to 3.4.4 you need to [**upgrade to 3.4.3 first**](#upgrading-sentient-ce-to-343).


</div>


#### SENTIENT image download

Download SENTIENT Docker image:

```bash
docker pull sentient/tb-postgres:3.4.4
```


#### SENTIENT service upgrade

* Stop SENTIENT `mytb` container if it is running.

```bash
docker compose stop mytb
```
 


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose stop mytb**


</div>


* Update docker-compose.yml

```yml
< . . . >
  mytbce:
    image: "sentient/tb-postgres:3.4.4"
< . . . >
```


* Start SENTIENT:

```bash
docker compose up -d
```


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose up -d**


</div>

### Upgrading SENTIENT to 3.4.2


<div class="st-callout info">


**NOTE:**
<br>
These upgrade steps are applicable for SENTIENT version 3.4.1. In order to upgrade to 3.4.2 you need to [**upgrade to 3.4.1 first**](#upgrading-sentient-ce-to-341).


</div>


#### SENTIENT image download

Download SENTIENT Docker image:

```bash
docker pull sentient/tb-postgres:3.4.2
```


#### SENTIENT service upgrade

* Stop SENTIENT `mytb` container if it is running.

```bash
docker compose stop mytb
```
 


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose stop mytb**


</div>


* Update docker-compose.yml

```yml
< . . . >
  mytbce:
    image: "sentient/tb-postgres:3.4.2"
< . . . >
```


* Change `upgradeversion` variable:

```bash
echo '3.4.1' | sudo tee ~/.mytb-data/.upgradeversion
```


* Execute the following commands to upgrade SENTIENT to the new version:

```bash
docker run -it -v ~/.mytb-data:/data --rm sentient/tb-postgres:3.4.2 upgrade-tb.sh
```


* Start SENTIENT:

```bash
docker compose up -d
```


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose up -d**


</div>


<div class="st-callout info">


Update the JWT signing key if you use the default one "sentientDefaultSigningKey" on production environments. See [JWT security settings](/docs/user-guide/ui/security-settings/#jwt-security-settings) for details.


</div>
