### Upgrading SENTIENT to 3.5.1


<div class="st-callout info">


**NOTE:**
<br>
These upgrade steps are applicable for SENTIENT version 3.5. In order to upgrade to 3.5.1 you need to [**upgrade to 3.5 first**](#upgrading-sentient-ce-to-350).


</div>


#### SENTIENT image download

Download SENTIENT Docker image:

```bash
docker pull sentient/tb-postgres:3.5.1
```


#### SENTIENT service upgrade

* Stop SENTIENT `mytb` container if it is running.

```bash
docker compose stop mytb
```
 


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose stop mytb**


</div>


* Update docker-compose.yml

```yml
< . . . >
  mytbce:
    image: "sentient/tb-postgres:3.5.1"
< . . . >
```


* Change `upgradeversion` variable:

```bash
echo '3.5.0' | sudo tee ~/.mytb-data/.upgradeversion
```


* Execute the following commands to upgrade SENTIENT to the new version:

```bash
docker run -it -v ~/.mytb-data:/data --rm sentient/tb-postgres:3.5.1 upgrade-tb.sh
```


* Start SENTIENT:

```bash
docker compose up -d
```


<div class="st-callout info">


If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose up -d**


</div>


### Upgrading SENTIENT to 3.5.0


<div class="st-callout info">


**NOTE:**
<br>
These upgrade steps are applicable for SENTIENT version 3.4.4. In order to upgrade to 3.5 you need to [**upgrade to 3.4.4 first**](/docs/user-guide/install/upgrade-instructions/docker/v3-4-x/#upgrading-sentient-ce-to-344).


</div>


<div class="st-callout warn">


**Important note before upgrading to SENTIENT 3.5**

SENTIENT UI was migrated to Angular 15. You need to re-build your custom widgets and rule nodes (which use UI) on Angular 15.

We suggest consulting [**this guide**](https://v15.material.angular.io/guide/mdc-migration).


</div>
