### Upgrading SENTIENT to 4.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.0.x.
In order to upgrade to 4.1 you need to [**upgrade to 4.0.x first**](/docs/user-guide/install/upgrade-instructions/docker/v4-0-x/#upgrading-sentient-ce-to-402).


</div>


#### SENTIENT service upgrade


1. Change the version of the `sentient/tb-node` in the `docker-compose.yml` file to the **4.1.0**.

2. Execute the following commands:


```bash
docker pull sentient/tb-node:4.1.0
docker compose stop sentient-ce
docker compose run --rm -e UPGRADE_TB=true sentient-ce 
docker compose up -d
```
