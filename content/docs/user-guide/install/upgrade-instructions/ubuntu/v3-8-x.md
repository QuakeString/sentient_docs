### Upgrading SENTIENT to 3.8.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.8.
In order to upgrade to 3.8.1 you need to [**upgrade to 3.8 first**](#upgrading-sentient-ce-to-38).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.8.1/sentient-3.8.1.deb
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo dpkg -i sentient-3.8.1.deb
```


<div class="st-callout info">


**NOTE:**
<br>
Package installer may ask you to merge your SENTIENT configuration. It is preferred to use merge option to make sure that all your previous parameters will not be overwritten.


</div>


#### Start the service


```bash
sudo service sentient start
```


### Upgrading SENTIENT to 3.8


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.7.
In order to upgrade to 3.8 you need to [**upgrade to 3.7 first**](/docs/user-guide/install/upgrade-instructions/ubuntu/v3-7-x/#upgrading-sentient-ce-to-37).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v3.8/sentient-3.8.deb
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo dpkg -i sentient-3.8.deb
```


<div class="st-callout info">


**NOTE:**
<br>
Package installer may ask you to merge your SENTIENT configuration. It is preferred to use merge option to make sure that all your previous parameters will not be overwritten.


</div>


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh --fromVersion=3.7.0
```


#### Start the service


```bash
sudo service sentient start
```
