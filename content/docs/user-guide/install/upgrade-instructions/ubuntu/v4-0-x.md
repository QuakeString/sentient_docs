### Upgrading SENTIENT to 4.0.2


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.9.x.
In order to upgrade to 4.0.2 you need to [**upgrade to 3.9.x first**](/docs/user-guide/install/upgrade-instructions/ubuntu/v3-9-x/#upgrading-sentient-ce-to-391).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.0.2/sentient-4.0.2.deb
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo dpkg -i sentient-4.0.2.deb
```


<div class="st-callout info">


**NOTE:**
<br>
Package installer may ask you to merge your SENTIENT configuration. It is preferred to use merge option to make sure that all your previous parameters will not be overwritten.


</div>


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```
