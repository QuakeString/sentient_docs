### Upgrading SENTIENT to latest 4.2.x (4.2.2.1)


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.0+.
In order to upgrade to 4.2.2.1 you need to [**upgrade to 4.2.0 first**](#upgrading-sentient-ce-to-42).


</div>


#### SENTIENT package download


```bash
wget https://github.com/sentient/sentient/releases/download/v4.2.2.1/sentient-4.2.2.1.deb
```


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```bash
sudo service sentient stop
```


```bash
sudo dpkg -i sentient-4.2.2.1.deb
```


<div class="st-callout info">


**NOTE:**
<br>
Package installer may ask you to merge your SENTIENT configuration. It is preferred to use merge option to make sure that all your previous parameters will not be overwritten.


</div>


<div class="st-callout warn">


If you are upgrading from 4.2, you **must** run the script below. However, if you are upgrading from version 4.2.1+, **DO NOT** run the upgrade script; proceed directly to starting the service.


</div>


```bash
sudo /usr/share/sentient/bin/install/upgrade.sh
```


#### Start the service


```bash
sudo service sentient start
```


    


### Upgrading SENTIENT to 4.2.1.2


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.0 or any 4.2.1 patch.
In order to upgrade to 4.2.1.2 you need to [**upgrade to 4.2.0 first**](#upgrading-sentient-ce-to-42).


</div>


<div class="st-callout warn">


This version has known security vulnerabilities that are fixed in newer releases. We recommend upgrading to the latest patch version instead.
