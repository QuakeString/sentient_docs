### Upgrading SENTIENT to 3.5.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.5.
In order to upgrade to 3.5.1 you need to [**upgrade to 3.5 first**](#upgrading-sentient-ce-to-35).


</div>


#### SENTIENT package download


Download SENTIENT installation file for Windows: [sentient-windows-3.5.1.zip](https://github.com/sentient/sentient/releases/download/v3.5.1/sentient-windows-3.5.1.zip).


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```
net stop sentient
```


* Make a backup of previous SENTIENT configuration located in \<SENTIENT install dir\>\conf (for ex. C:\sentient\conf).
* Remove SENTIENT install dir.
* Unzip installation archive to SENTIENT install dir.
* Compare and merge your old SENTIENT configuration files (from the backup you made in the first step) with new ones.


<div class="st-callout info">


**NOTE:**
<br>
Scripts listed above should be executed using Administrator Role.


</div>


Execute regular upgrade script:

```
C:\sentient>upgrade.bat --fromVersion=3.5.0
```


#### Start the service
```
net start sentient
```


### Upgrading SENTIENT to 3.5


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.4.4.
In order to upgrade to 3.5 you need to [**upgrade to 3.4.4 first**](/docs/user-guide/install/upgrade-instructions/windows/v3-4-x/#upgrading-sentient-ce-to-344).


</div>


<div class="st-callout warn">


**Important note before upgrading to SENTIENT 3.5**

SENTIENT UI was migrated to Angular 15. You need to re-build your custom widgets and rule nodes (which use UI) on Angular 15.
