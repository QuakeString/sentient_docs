### Upgrading SENTIENT to 3.7


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.6.4.
In order to upgrade to 3.7 you need to [**upgrade to 3.6.4 first**](/docs/user-guide/install/upgrade-instructions/windows/v3-6-x/#upgrading-sentient-ce-to-364).


</div>


<div class="st-callout warn">


**Important note before upgrading to SENTIENT 3.7**

SENTIENT backend was migrated to Java 17. Install JDK 17 and ensure that system's default Java version is set to 17.

Please refer to [**Step 1 of the installation guide**](/docs/user-guide/install/windows/#step-1-install-java-17-openjdk) for detailed instructions.


</div>


#### SENTIENT package download


Download SENTIENT installation file for Windows: [sentient-windows-3.7.zip](https://github.com/sentient/sentient/releases/download/v3.7/sentient-windows-3.7.zip).


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```
net stop sentient
```


* Make a backup of previous SENTIENT configuration located in \<SENTIENT install dir\>\conf (for ex. C:\sentient\conf).
* Remove SENTIENT install dir.
* Unzip installation archive to SENTIENT install dir.
* Compare and merge your old SENTIENT configuration files (from the backup you made in the first step) with new ones.


<div class="st-callout info">


**NOTE:**
<br>
Scripts listed above should be executed using Administrator Role.


</div>


Execute regular upgrade script:

```
C:\sentient>upgrade.bat --fromVersion=3.6.4
```


#### Start the service
```
net start sentient
```
