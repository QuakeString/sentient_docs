### Upgrading SENTIENT to 3.8.1


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.8.
In order to upgrade to 3.8.1 you need to [**upgrade to 3.8 first**](#upgrading-sentient-ce-to-38).


</div>


#### SENTIENT package download


Download SENTIENT installation file for Windows: [sentient-windows-3.8.1.zip](https://github.com/sentient/sentient/releases/download/v3.8.1/sentient-windows-3.8.1.zip).


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```
net stop sentient
```


* Make a backup of previous SENTIENT configuration located in \<SENTIENT install dir\>\conf (for ex. C:\sentient\conf).
* Remove SENTIENT install dir.
* Unzip installation archive to SENTIENT install dir.
* Compare and merge your old SENTIENT configuration files (from the backup you made in the first step) with new ones.


#### Start the service
```
net start sentient
```


### Upgrading SENTIENT to 3.8


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 3.7.
In order to upgrade to 3.8 you need to [**upgrade to 3.7 first**](/docs/user-guide/install/upgrade-instructions/windows/v3-7-x/#upgrading-sentient-ce-to-37).


</div>


#### SENTIENT package download


Download SENTIENT installation file for Windows: [sentient-windows-3.8.zip](https://github.com/sentient/sentient/releases/download/v3.8/sentient-windows-3.8.zip).


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```
net stop sentient
```


* Make a backup of previous SENTIENT configuration located in \<SENTIENT install dir\>\conf (for ex. C:\sentient\conf).
* Remove SENTIENT install dir.
* Unzip installation archive to SENTIENT install dir.
* Compare and merge your old SENTIENT configuration files (from the backup you made in the first step) with new ones.


<div class="st-callout info">


**NOTE:**
<br>
Scripts listed above should be executed using Administrator Role.


</div>


Execute regular upgrade script:

```
C:\sentient>upgrade.bat --fromVersion=3.7.0
```


#### Start the service
```
net start sentient
```
