### Upgrading SENTIENT to latest 4.2.x (4.2.2.1)


<div class="st-callout info">


**NOTE:**

These upgrade steps are applicable for SENTIENT version 4.2.0+.
In order to upgrade to 4.2.2.1 you need to [**upgrade to 4.2.0 first**](#upgrading-sentient-ce-to-42).


</div>


#### SENTIENT package download


Download SENTIENT installation file for Windows: [sentient-windows-4.2.2.1.zip](https://github.com/sentient/sentient/releases/download/v4.2.2.1/sentient-windows-4.2.2.1.zip).


#### SENTIENT service upgrade

* Stop SENTIENT service if it is running.

```
net stop sentient
```


* Make a backup of previous SENTIENT configuration located in \<SENTIENT install dir\>\conf (for ex. C:\sentient\conf).
* Remove SENTIENT install dir.
* Unzip installation archive to SENTIENT install dir.
* Compare and merge your old SENTIENT configuration files (from the backup you made in the first step) with new ones.


<div class="st-callout warn">


If you are upgrading from 4.2, you **must** run the script below. However, if you are upgrading from version 4.2.1+, **DO NOT** run the upgrade script; proceed directly to starting the service.


</div>


Execute regular upgrade script:

```
C:\sentient>upgrade.bat
```


#### Start the service
```
net start sentient
```
