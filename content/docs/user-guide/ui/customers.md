A **Customer** in SENTIENT represents a distinct business entity — an individual or an organization — that purchases or uses a tenant&#39;s devices and/or assets. A customer may also represent a department or subdivision within the tenant&#39;s organization.

A customer user belongs to the customer and has read permissions to view dashboards and other entities assigned by the tenant administrator.

In Sentient Community Edition a customer user cannot create their own customers, users, or subcustomers.


<div class="st-callout info">


**Important:**
<br>
In **Sentient Professional Edition** customer user can create other customers, users and subcustomers.
To try this functionality, use the [SENTIENT Cloud](https://localhost/signup) server.
The alternative option is to install SENTIENT locally using this [installation guide](/docs/installation/)


</div>


[Tenant administrators](/docs/user-guide/ui/tenants/) can create customer and can directly manage their [assets](/docs/user-guide/ui/assets/), [devices](/docs/user-guide/ui/devices/),
[dashboards](/docs/user-guide/dashboards/), and [edges](/docs/edge/) from the customer details page by clicking the related tab.

## Create new customer

The tenant administrator can add a new customer using the following steps.


1. Navigate to the "Customers" page. Then click the plus sign in the upper right corner of the screen;

1. In the opened dialog box, fill in the title of the customer. Also, you can optionally indicate country name, city, address, and phone number. Then click "Add";

1. New customer is created. You can view and manage both users and entities (devices, assets, dashboards, etc.) for any customer directly from their row in the Customers table.

## Create customer user

The tenant administrator can add a customer user using the following steps.


1. Navigate to the "Customers" page. Then click on the "Manage customer users" icon located on the customer`s row to whom you want to add a customer user;

1. Click the plus sign in the upper right corner of the screen. In the opened dialog box, enter the email address, first and last name of the user. Then choose activation method: display activation link or send activation link via email. Then click "Add";

1. If you selected the option "Show activation link", copy the link address and send it to the user. Click "OK";

1. New customer user is created.

## Edit customer

The tenant administrator can edit the title, specify a home dashboard and edit the rest of the fields for the customer. 
Let’s see how to do this:


1. Click on the customer to open their details. Click the "pencil" icon to enter edit mode;

1. Edit the fields. For example, you can specify a home dashboard for this customer and all its customer users. After that, save all changes;

1. You have updated customer information.

## Delete customer or customer user

The tenant administrator can delete a customer along with all its customer users using one of the following ways:

First way:


1. Click a trash icon can opposite the customer`s name you want to delete;

1. Confirm deleting the customer in the dialog box.

Second way:


1. Click on the customer that you want to delete. In the customer details, click "Delete customer" button;

1. Confirm deleting the customer in the dialog box.

You can also delete multiple customers at once.


1. Mark one or multiple customers you want to delete. Click on the trash bin icon in the top right corner;

1. Confirm deleting customers in the dialog box.

1. Click a trash icon can opposite the name of the customer user you want to delete. Confirm deleting the customer user in the dialog box.

## Customer details

Clicking on a customer opens a details window where you can view and manage all aspects related to that customer.


<div class="st-gallery"><figure><img src="/images/user-guide/ui/customers/ce/customer-details-page-1-ce.webp" alt="Clicking on a customer opens a details window where you can view and manage all aspects related to that customer." loading="lazy"><figcaption>Clicking on a customer opens a details window where you can view and manage all aspects related to that customer.</figcaption></figure></div>


<b><font size="3">Copy customer ID</font></b>   
Allows you to quickly retrieve the customer’s unique UUID. Click Copy customer Id to copy it to your clipboard. This ID is used in API calls, integrations, and automation scripts.

<b><font size="3">Attributes</font></b>

This tab displays client, server, and shared [attributes](/docs/user-guide/attributes/) associated with the customer. These are static or semi-static key-value pairs, such as contact information, region, account parameters, or custom metadata.

<b><font size="3">Latest telemetry</font></b>

Shows the [latest telemetry](/docs/user-guide/telemetry/) values linked to the customer. Telemetry can be generated by customer-related devices, services, or added manually for analytics and modeling purposes.
- **Adding telemetry:** Click the "**+**" icon, then define the key, value type, and value.
- **Deleting telemetry:** Click the trash icon, select the deletion mode (all data, latest value, all except latest, or by time range), and confirm the action.

<b><font size="3">Calculated fields</font></b>   
Displays fields whose values are computed from existing attributes or telemetry using formulas. Useful for deriving additional business metrics at the customer level. Learn more about Calculated fields [here](/docs/user-guide/calculated-fields/).

<b><font size="3">Alarm rules</font></b>   
Contains alarm rules configured for the customer. These rules define how alarms are generated based on customer-level data or associated assets/devices. Learn more about configuring alarm rules [here](/docs/user-guide/alarm-rules/).

<b><font size="3">Alarms</font></b>  
Shows all active and historical [alarms](/docs/user-guide/alarms/) related to the customer. Helps track operational issues, warnings, and critical events affecting the customer or their infrastructure.

<b><font size="3">Events</font></b>   
Displays system events associated with the customer — logs, warnings, errors, and lifecycle activities. Useful for diagnostics and monitoring customer-related operations.

<b><font size="3">Relations</font></b>   
Shows all directed [relationships](/docs/user-guide/entities-and-relations/#relations) between the customer and other entities, such as assets, devices, dashboards, or rule chains. Provides a structural overview of the customer's environment in the system.

<b><font size="3">Audit logs</font></b>   
Provides a [record of user actions](/docs/user-guide/audit-log/) related to the customer — creation, updates, configuration changes, and deletions. Supports security auditing and change tracking.

<b><font size="3">Version control</font></b>   
Allows exporting and restoring customer-related entities using the Git-based [version control](/docs/user-guide/version-control/) service. Useful for backups, collaborative workflows, and configuration versioning.
