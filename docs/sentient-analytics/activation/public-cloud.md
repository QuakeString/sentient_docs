This guide describes how to activate SENTIENT ANALYTICS in your SENTIENT public Cloud environment via the Billing page.

## Activation Steps

### Step 1. Open the Billing Page

* Log in to your SENTIENT Cloud environment.
* In the left-side navigation menu, open the **Plan and Billing** page.

{% include images-gallery.html imageCollection="step-1" %}

### Step 2. Add the SENTIENT ANALYTICS add-on

**Option A: Add SENTIENT ANALYTICS add-on only**

* Click the **Add to plan +** button in the SENTIENT ANALYTICS row.
* Click the **Next: Summary** button.

{% include images-gallery.html imageCollection="step-2-option-a" %}

**Option B: Change subscription plan and add SENTIENT ANALYTICS add-on**

* Click the **Update plan** button.
* In the modal that appears, select the most suitable plan for your business goals and click the **Customize** or **Select** button.
* In the Customize step, enable the **SENTIENT ANALYTICS** add-on.
* Click the **Next: Summary** button.

{% include images-gallery.html imageCollection="step-2-option-b" %}

### Step 3. Activate plan

* Review your plan configuration to ensure everything is correct.
* If you have a coupon code, click **Apply coupon** button and submit it.
* Click the **Update plan** button to activate your plan.
* Verify that **SENTIENT ANALYTICS** 

{% include images-gallery.html imageCollection="step-3" %}

### Step 4. Access SENTIENT ANALYTICS Interface

You can access the SENTIENT ANALYTICS interface using the following links:

* [SENTIENT ANALYTICS Cloud (US)](https://sentient.cloud/sentient-analytics/){:target="_blank"} 
* [SENTIENT ANALYTICS Cloud (EU)](https://eu.sentient.cloud/sentient-analytics/){:target="_blank"}
