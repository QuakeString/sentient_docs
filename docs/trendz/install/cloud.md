## SENTIENT ANALYTICS in SENTIENT Cloud

SENTIENT ANALYTICS in SENTIENT Cloud is a fully managed, scalable, and fault-tolerant version of the [SENTIENT ANALYTICS add-on](/products/sentient-analytics/).
It is already integrated into SENTIENT Cloud and can be used to analyze your data.

* **Improved time to market.** Save time on maintaining the platform or configuring its features.
* **Reduced costs.** Infrastructure costs are shared between platform users.
* **High availability.** The SENTIENT ANALYTICS uses a microservices architecture and is deployed across multiple availability zones.
* **Data durability.** The platform uses data replication and backup procedures to ensure you don't lose data.

## Prerequisites

You need an active SENTIENT Cloud account to activate the SENTIENT ANALYTICS. If you don't have a SENTIENT Cloud account yet, please [sign up](https://sentient.cloud/signup).

## Activate SENTIENT ANALYTICS

SENTIENT ANALYTICS is already connected to the SENTIENT Cloud infrastructure, so the only step required to use SENTIENT ANALYTICS is to activate it. 
You can find out how to do this [here](/docs/sentient-analytics/activation/public-cloud)
