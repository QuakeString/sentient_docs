### Upgrading SENTIENT ANALYTICS to 1.13.2

{% capture upgrade_version_by_version%}
**NOTE**:
<br>
After upgrading it is required to update SENTIENT ANALYTICS widget bundle in SENTIENT. You can find detailed instructions how to do that via SENTIENT ANALYTICS UI in [SENTIENT ANALYTICS Widget Bundle upgrade](/docs/sentient-analytics/post-installation-steps/#sentient-analytics-widget-bundle) article.
<br>
You can upgrade SENTIENT ANALYTICS from any version to the 1.13.2.
{% endcapture %}
{% include templates/info-banner.md content=upgrade_version_by_version %}

#### SENTIENT ANALYTICS image download

Download SENTIENT ANALYTICS Docker image:

```bash
docker pull sentient/sentient-analytics:1.13.2
```
{: .copy-code}

#### SENTIENT ANALYTICS service upgrade

* Create a dump of your database:

```bash
docker compose exec postgres sh -c "pg_dump -U postgres sentient-analytics > /var/lib/postgresql/data/sentient-analytics_dump"
```
{: .copy-code}

{% capture dockerComposeStandalone %}
If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose exec postgres sh -c "pg_dump -U postgres sentient-analytics > /var/lib/postgresql/data/sentient-analytics_dump"**
{% endcapture %}
{% include templates/info-banner.md content=dockerComposeStandalone %}

* Stop SENTIENT ANALYTICS `sentient-analytics` container if it is running.

```bash
docker compose stop sentient-analytics
```
{: .copy-code}

* Set upgradeversion variable to your **previous** SENTIENT ANALYTICS version.

```bash
docker compose exec sentient-analytics sh -c "echo '1.13.1' > /data/.upgradeversion" 
```
{: .copy-code}

{% capture dockerComposeStandalone %}
If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose exec mysentient-analytics sh -c "echo '1.13.1' > /data/.upgradeversion"**
{% endcapture %}
{% include templates/info-banner.md content=dockerComposeStandalone %}

* Update `docker-compose.yml`:

```yml
< . . . >
  sentient-analytics:
    image: "sentient/sentient-analytics:1.13.2"
  sentient-analytics-python-executor:
    image: "sentient/sentient-analytics-python-executor:1.13.2"  
< . . . >
```
{: .copy-code}

* Start SENTIENT ANALYTICS:

```bash
docker compose up -d
```
{: .copy-code}
