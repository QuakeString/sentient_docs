### Upgrading SENTIENT ANALYTICS to 1.8.2

{% capture upgrade_version_by_version%}
**NOTE**: You can upgrade SENTIENT ANALYTICS from any version to the 1.8.2.
{% endcapture %}
{% include templates/info-banner.md content=upgrade_version_by_version %}

#### SENTIENT ANALYTICS image download

Download SENTIENT ANALYTICS Docker image:

```bash
docker pull sentient/sentient-analytics:1.8.2
```
{: .copy-code}

#### SENTIENT ANALYTICS service upgrade

* Create a dump of your database:

```bash
docker compose exec postgres sh -c "pg_dump -U postgres sentient-analytics > /var/lib/postgresql/data/sentient-analytics_dump"
```
{: .copy-code}

{% capture dockerComposeStandalone %}
If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose exec postgres sh -c "pg_dump -U postgres sentient-analytics > /var/lib/postgresql/data/sentient-analytics_dump"**
{% endcapture %}
{% include templates/info-banner.md content=dockerComposeStandalone %}

* Stop SENTIENT ANALYTICS `sentient-analytics` container if it is running.

```bash
docker compose stop sentient-analytics
```
{: .copy-code}

* Set upgradeversion variable to your **previous** SENTIENT ANALYTICS version (if you`re upgrading from 1.8.1 set upgradeversion to 1.8.1).

```bash
docker compose exec sentient-analytics sh -c "echo '1.8.1' > /data/.upgradeversion" 
```
{: .copy-code}

{% capture dockerComposeStandalone %}
If you still rely on Docker Compose as docker-compose (with a hyphen) execute next command:
<br>**docker-compose exec mysentient-analytics sh -c "echo '1.8.1' > /data/.upgradeversion"**
{% endcapture %}
{% include templates/warn-banner.md content=old_manifests_info %}

* Update `docker-compose.yml`:

```yml
< . . . >
  sentient-analytics:
    image: "sentient/sentient-analytics:1.8.1"
< . . . >
```
{: .copy-code}

* Start SENTIENT ANALYTICS:

```bash
docker compose up -d
```
{: .copy-code}
