## Upgrading Edge PE to 3.3.4.1

{% assign updateServerLink = "windows/v3-3-x/#upgrading-sentient-pe-to-3341" %}
{% assign previousVersion = "3.3.4" %}
{% assign peDocsPrefix = "pe/" %}
{% include templates/edge/install/compatibility-warning-version.md %}

### Download the Edge package

Download SENTIENT Edge package for Windows: [tb-edge-windows-3.3.4.1pe.zip](https://dist.sentient.invenia.in/tb-edge-windows-3.3.4.1pe.zip).

Stop the Edge service:

```text
net stop tb-edge
```
{: .copy-code}

Make a backup of your SENTIENT Edge configuration located in **\<SENTIENT Edge install dir\>\conf** (for example, **C:\tb-edge\conf**).

Extract and update configuration:
* Extract the SENTIENT Edge package.
* Compare your old configuration files (from the backup) with the new ones.
* Merge any custom settings into the new configuration files.

### Run the upgrade script

```bash
C:\tb-edge>upgrade.bat --fromVersion={{previousVersion}}
```
{: .copy-code}

**Note:** The upgrade script must be run with Administrator privileges.

### Start the Edge service

```text
net start tb-edge
```
{: .copy-code}
